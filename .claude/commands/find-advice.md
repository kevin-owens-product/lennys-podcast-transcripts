# Find Podcast Advice

Search through Lenny's Podcast transcripts to find specific advice on a topic from the guest experts.

## Instructions

When the user asks about a topic:

1. Search across all `episodes/*/transcript.md` files for the topic keywords
2. Read relevant sections from matching transcripts
3. Synthesize the advice from multiple guests, citing specific quotes with attribution
4. Note areas of agreement and disagreement between guests
5. Provide actionable takeaways
